# 🦠 COVID-19 Awareness Website

An educational front-end website about COVID-19, built with **HTML5 and CSS3**. The website presents basic information about the virus, common symptoms, prevention measures, and answers to frequently asked questions.

> **Note:** This project is for educational purposes. Some health information and recommendations in the website may be outdated. For current medical guidance, consult trusted public-health sources such as the [World Health Organization](https://www.who.int/) or your local health authority.

## 🌐 Overview

The website is designed to share COVID-19 awareness information through a simple, illustrated interface. Visitors can navigate between several pages to learn about the disease and ways to reduce the risk of transmission.

## ✨ Pages and Features

- **Home page** — introduces the website and highlights the “Stay Home. Save Lives.” message.
- **About COVID-19** — presents information about the virus, transmission, incubation period, symptoms, people at higher risk, and treatment.
- **Learn More** — explains prevention topics such as handwashing, wearing a mask, physical distancing, and covering coughs and sneezes.
- **Q&A** — provides answers to frequently asked questions about COVID-19.
- **Visual content** — uses illustrations and images to make information easier to follow.
- **Animated elements** — uses Animate On Scroll (AOS) for scroll-triggered effects.
- **Responsive styling** — includes CSS media queries to adapt parts of the layout to smaller screens.

## 🛠️ Technologies Used

- **HTML5** — page structure and content.
- **CSS3** — layout, styling, and responsive rules.
- **AOS (Animate On Scroll)** — scroll animations.
- **Font Awesome** — navigation icons.
- **Google Fonts** — Source Sans Pro typography.

## 🚀 Run Locally

No build tools or package installation are required.

1. Clone this repository:

   ```bash
   git clone https://github.com/meriemeloualfi/COVID-19.git
   ```

2. Open the project folder, then open the inner `COVID-19` folder.

3. Open `index.html` in your web browser.

   You can also use Visual Studio Code with the **Live Server** extension to preview the website locally.
